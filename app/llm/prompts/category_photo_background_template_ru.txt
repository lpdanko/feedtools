Ты создаешь фоновый шаблон для дополнительного фото товара в карточке маркетплейса.

Вход:
- CATEGORY JSON с названием и путем категории.
- COVER DESIGN TEXT с описанием визуального стиля категории.

Задача:
Создай только красивый задний план в стиле COVER DESIGN TEXT. Это не готовое товарное фото, а чистая основа, на которую позже будут программно добавлены характеристики товара текстом.
Размер изображения должен быть ровно 1200×1600, вертикальный формат 3:4 для Ozon.
Фон должен быть универсальным внутри этой категории, но не безликим: по изображению должно быть понятно, к какой категории относится шаблон.

Очень важно:
- Не изображай конкретный продаваемый товар, упаковку, руки, людей, витрину или предметы в центре кадра.
- Разрешены только фоновые тематические элементы категории: тонкий чертеж, полупрозрачный контур, схема, силуэт, техническая линия, паттерн материала или деталь, характерная для категории. Например, для аккумуляторов смартфонов уместен едва заметный контур телефона, батарейный символ, контакты, схемные линии; для автозапчастей — технический чертеж детали; для кабелей — мягкие линии проводов и разъемов. Эти элементы должны быть декоративными, не как отдельный товар.
- Тематические элементы должны быть привязаны к CATEGORY JSON и COVER DESIGN TEXT. Не делай абстрактный техно-фон, если категория позволяет показать узнаваемую схему/контур.
- Не добавляй текст, буквы, цифры, псевдо-текст, логотипы, QR-коды, иконки маркетплейсов, цены, скидки или водяные знаки.
- Не рисуй несколько отдельных пустых карточек, плашек, прямоугольников, бейджей, табличек или контейнеров под текст.
- Не создавай готовый layout для будущего текста. Текстовые блоки, карточки и отступы будут добавлены позже программно поверх изображения.
- Фон должен быть универсальным для товаров этой категории: одна цельная композиция на весь кадр, без заранее размеченных мест под разные характеристики.
- Если нужна зона для будущего текста, сделай максимум одну большую спокойную область без четкой рамки и без тени: мягкий светлый участок, градиент или свободное пространство, куда можно поставить список характеристик.
- Лучше использовать такой фон, на котором текст можно читать без отдельной плашки: чистые контрастные зоны, мягкие переходы, умеренные паттерны.
- Фон должен быть аккуратным, современным, пригодным для карточки маркетплейса и хорошо читаемым после добавления текста.
- Композиция вертикальная, без перегруза деталями. Никаких центральных объектов и декоративных рамок, которые могут конфликтовать с будущим товаром или текстом.
- Можно использовать цвет, градиенты, мягкие формы, линии, свет, легкие паттерны и декоративные элементы, если они соответствуют стилю категории.
- Категорийный декор держи по краям, в углах или в глубине фона: крупный, но низкоконтрастный, полупрозрачный, без резких границ. Он должен добавлять узнаваемость категории, а не спорить с будущим текстом.
- Держи большое чистое пространство в центре/верхней половине. Не делай три и более визуально равных блока.

Верни только изображение.
